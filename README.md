# Lorebook Sync

Расширение для **SillyTavern**: синхронизация лорбуков (World Info) в базу **Notion**.

Позже: карточки персонажей и персоны. Обсидиан — не в приоритете.

## Установка

1. Откройте SillyTavern → **Extensions** → **Install extension**.
2. Вставьте ссылку на репозиторий: https://github.com/satsvi97/lorebook-sync
3. Нажмите Install и перезагрузите страницу.

## Настройка

1. Создайте интеграцию: Notion → Settings → Connections → Develop or manage integrations → New integration.
2. Скопируйте **Internal Integration Secret** (начинается с ntn_).
3. Создайте базу в Notion с колонкой Name (тип Title).
4. Нажмите в базе Share и добавьте свою интеграцию.
5. Скопируйте ID базы из ссылки: https://www.notion.so/<workspace>/<DATABASE_ID>?v=...
6. В SillyTavern откройте настройки расширения и вставьте токен и ID базы.
7. Нажмите «Проверить связь», затем «Синхронизировать в Notion».

## Что делает v0.1

- Читает список лорбуков через /api/worldinfo/list.
- Читает содержимое каждого лорбука через /api/worldinfo/get.
- Создаёт страницу в базе Notion (или обновляет существующую с тем же именем).
- Каждая запись лорбука превращается в заголовок heading_3 (имя + ключи) и текст записи.

## Безопасность

Токен хранится локально в настройках SillyTavern (extensionSettings, обычный текст).
Не публикуйте токен и не коммитьте его в репозиторий. Если токен утёк — удалите интеграцию в Notion.
