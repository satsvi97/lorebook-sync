# Lorebook Sync

Расширение для **SillyTavern**: синхронизация данных Таверны в базы **Notion**.

## Что синхронизируется

Четыре независимые категории — у каждой своя база Notion:

| Категория | Откуда берётся | Куда пишется |
|---|---|---|
| 📚 Лорбуки | `/api/worldinfo/list` + `/api/worldinfo/get` | страница на лорбук |
| 🎭 Персонажи | карточки персонажей ST | страница на персонажа |
| 🧑 Персоны | `power_user.personas` + описания | страница на персону |
| 💬 Чаты | `/api/characters/chats` + `/api/chats/get` | страница на чат |

## Установка

1. Откройте SillyTavern → **Extensions** → **Install extension**.
2. Вставьте ссылку: https://github.com/satsvi97/lorebook-sync
3. Нажмите Install и перезагрузите страницу.

## Настройка

1. Создайте интеграцию: Notion → Settings → Connections → Develop or manage integrations → New integration.
2. Скопируйте **Internal Integration Secret** (начинается с ntn_).
3. Создайте отдельные базы в Notion (для лорбуков, персонажей, персон и чатов).
4. Нажмите в каждой базе **Share** и добавьте интеграцию.
5. Скопируйте ID каждой базы из её ссылки: https://www.notion.so/<workspace>/<DATABASE_ID>?v=...
6. В настройках расширения вставьте токен и ID баз.
7. Нажмите «Проверить связь», затем нужный **Sync** или «Синхронизировать всё».

## Как обновляются страницы

- Поиск идёт по свойству типа `title` (обычно `Name`).
- Если страница с таким именем уже есть — её содержимое перезаписывается.
- Если нет — создаётся новая.

## Ограничения

- Чаты: по умолчанию последние 5 чатов на персонажа и 300 сообщений в чате (настраивается).
- Пустые лорбуки по умолчанию пропускаются.

## Безопасность

Токен хранится локально в настройках SillyTavern (`extensionSettings`, обычный текст).
Не публикуйте токен и не коммитьте его в репозиторий. Если токен утёк — удалите интеграцию в Notion.
