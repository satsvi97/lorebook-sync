# Lorebook Sync (в разработке)

Расширение для **SillyTavern**: синхронизация данных Таверны в базы **Notion**.

## Что синхронизируется

Четыре независимые категории — у каждой своя база Notion:

| Категория | Откуда берётся | Куда пишется |
|---|---|---|
| 📚 Лорбуки | `/api/worldinfo/list` + `/api/worldinfo/get` | страница на лорбук |
| 🎭 Персонажи | карточки персонажей ST | страница на персонажа |
| 🧑 Персоны | `power_user.personas` + описания | страница на персону |
| 💬 Чаты | `/api/characters/chats` + `/api/chats/get` | страница на чат |

## Установка

1. Откройте SillyTavern → **Extensions** → **Install extension**.
2. Вставьте ссылку: https://github.com/satsvi97/lorebook-sync
3. Нажмите Install и перезагрузите страницу.

## Настройка

1. Создайте интеграцию: Notion → Settings → Connections → Develop or manage integrations → New integration.
2. Скопируйте **Internal Integration Secret** (начинается с ntn_).
3. Создайте отдельные базы в Notion (для лорбуков, персонажей, персон и чатов).
4. Нажмите в каждой базе **Share** и добавьте интеграцию.
5. Скопируйте ID каждой базы из её ссылки: https://www.notion.so/<workspace>/<DATABASE_ID>?v=...
6. В настройках расширения вставьте токен и ID баз.
7. Нажмите «Проверить связь», затем нужный **Sync** или «Синхронизировать всё».

## Автоматическое создание баз

Кнопка **«Создать недостающие базы»** создаёт пустые базы Notion для категорий,
у которых не указан ID, и сразу подставляет их в поля:

- если база с таким названием уже есть — она будет использована повторно, дубль не создастся;
- поиск нечёткий: `✦ Lorebook Sync ✦` тоже считается базой лорбуков (по слову `lorebook`);
- если подходящих баз несколько — расширение ничего не угадывает и просит указать ID вручную;
- родительская страница берётся из любой уже указанной базы;
- если баз нет вообще — вставьте ID страницы Notion в поле
  «ID страницы Notion для новых баз».

Кнопка **«🔍 Найти базы по названию»** только ищет и подставляет ID, ничего не создавая.
Тот же поиск выполняется автоматически при открытии настроек, если какие-то поля пусты.

## Язык интерфейса

Под плашкой версии — четыре кнопки (RU / EN / UK / SV) в столбик. Переключают только
тексты расширения, на язык SillyTavern и настройки чата это не влияет.

## Версия

В правом верхнем углу настроек маленький индикатор версии — сверяется с `manifest.json`.

## Как обновляются страницы

- Поиск идёт по свойству типа `title` (обычно `Name`).
- Если страница с таким именем уже есть — её содержимое перезаписывается.
- Если нет — создаётся новая.

## Инкрементальная синхронизация

- В каждой базе используется свойство `Sync` (rich_text) — в нём хранится отпечаток последней записи.
- Лорбуки, персонажи и персоны: если содержимое не изменилось, страница **не перезаписывается**.
- Чаты: по умолчанию **дописываются** только новые сообщения. Если чат стал короче или нужна
  полная перезапись — включите галочку «перезаписывать чаты целиком».

## Аватары в карточках

Галочка «загружать аватары в карточки Notion» (включена по умолчанию) загружает
аватар персонажа или персоны в Notion через `file_uploads` и ставит его обложкой
и иконкой страницы — в галерее базы карточка показывает картинку.

- персонажи: файл берётся из `/characters/<avatar>`;
- персоны: из `/User%20Avatars/<file>`;
- загрузка выполняется только при первом синке страницы или когда контент изменился;
  повторно аватар не перезаливается (флаг `av=1` в свойстве `Sync`);
- если файл не найден, синхронизация продолжается, в лог пишется предупреждение.

## Импорт обратно (Notion → SillyTavern)

При синхронизации на каждой странице сохраняется снимок данных — блок кода
с маркером `⟦ls-snapshot:v1 …⟧`. Поэтому бэкап можно развернуть обратно:

- **Восстановить лорбуки** — пишет файлы через `/api/worldinfo/edit`. Если у страницы
  нет снимка (писалась до v0.6), записи собираются из текста страницы.
- **Восстановить персонажей** — отсутствующие карточки **создаются** через
  `/api/characters/create` вместе с аватаром из обложки Notion; существующие
  обновляются через `/api/characters/edit-attribute`.
- **Восстановить персон** — добавляет персоны в `power_user.personas`, аватар
  заливается через `/api/avatars/upload`, настройки сохраняются через `saveSettings()`.

По умолчанию существующее не перезаписывается; включите «перезаписывать существующее»,
чтобы принудительно заменить. После импорта обновите страницу (F5).

## Экспорт в Markdown (Obsidian)

Блок **«📦 Экспорт в Markdown (Obsidian)»** собирает все базы в `.zip` с `.md` файлами
(папки `Lorebooks/`, `Characters/`, `Personas/`, `Chats/`) и скачивает архив. Никаких
плагинов и портов: распакуйте архив в папку vault — Obsidian сам всё проиндексирует.

- в каждом файле — YAML-фронтматтер: `title`, `category`, `notion_id`, `notion_url`, `last_edited`;
- снимки `⟦ls-snapshot:v1 …⟧` в Markdown не попадают (это служебный бэкап для импорта);
- чаты выключены по умолчанию — галочка «включать чаты (может быть долго)»;
- синхронизация между устройствами — уже задача Obsidian: Obsidian Sync, Syncthing, iCloud,
  OneDrive или плагин git. Со стороны расширения это просто набор текстовых файлов.

## Авто-синхронизация

Галочка «авто-синхронизация активного чата» включает фоновую синхронизацию:
после каждых N полученных сообщений расширение дописывает новые сообщения
**только текущего чата** в базу чатов. N настраивается в поле ниже.

- работает только для обычных (одиночных) чатов; групповые пропускаются;
- не запускается поверх другой синхронизации;
- счётчик живёт в памяти и сбрасывается при перезагрузке страницы.

## Ограничения

- Чаты: по умолчанию последние 5 чатов на персонажа и 300 сообщений в чате (настраивается).
- Пустые лорбуки по умолчанию пропускаются.

## Безопасность

Токен хранится локально в настройках SillyTavern (`extensionSettings`, обычный текст).
Не публикуйте токен и не коммитьте его в репозиторий. Если токен утёк — удалите интеграцию в Notion.
